# ドキュメント

機能を足す・変えるときは、同じ作業ブランチでドキュメントも直す。

| ファイル | 直すとき |
|---|---|
| `docs/features.md` | 機能を足した・動きを変えたとき（ほぼ毎回） |
| `docs/requirements.md` | 権限・ポリシー・Google Play への対応・技術的負債が変わったとき |
| `docs/architecture.md` | ファイルの分け方や部品のつながりが変わったとき（Mermaid の図も） |
| `docs/store-listing.md` | PRO の機能・価格・掲載文が変わったとき |

- 文体は、ですます調ではなく「〜する」「〜にする」の常体で書く（既存のドキュメントに合わせる）。
- 実装の理由（なぜそうしたか）も短く書く。
