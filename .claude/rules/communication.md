# やり取りのルール

- 返事はすべて日本語で書く（最初の返事から）。
- 実機での確認はユーザーが行う。こちらは**ビルドが通るところまで**やって報告する。
  実機で試していないことは、「実機では試していない」とはっきり書く。
- 報告は短く、何を変えたか・どこを確かめてほしいかを先に書く。
  実機で確認してほしい操作があれば、具体的に挙げる。
- 提案や質問で終わる場合は、おすすめを1つ示す（選択肢を並べるだけにしない）。
- ユーザーが「進めて」「お願い」と言ったら、確認を挟まずに実装まで進める。
- 見た目の調整（大きさ・速さ・余白など）は、まず控えめに変えて、数値を調整できることを伝える。
  ユーザーの反応を見て戻すこともある（例：ページ送り → 無段階スクロールに戻した）。
