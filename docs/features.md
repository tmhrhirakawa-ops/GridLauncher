# GridLauncher 機能一覧

対応する主要ソースファイルを併記する。

## 1. ホーム画面 (`CyberLauncherScreen.kt`)

- 画面モードを3種類に分けてレイアウトを切替
  - 縦画面（小）: 縦画面かつ画面幅 600dp 未満（スマホ・折りたたみ端末のカバー画面など）
  - 縦画面（大）: 縦画面かつ画面幅 600dp 以上（タブレット・折りたたみ端末の展開時など）
  - 横画面
- 画面モードごとに、ウィジェットの配置を別々に保存（「2. ウィジェットキャンバス」参照）
- 上方向へのスワイプでアプリドロワーを表示
- 空白タップでウィジェット編集モードを解除
- 何もないところの長押しで、「ウィジェットを追加」「カスタマイズ」のメニューを表示（`HomeLongPressMenu.kt`）
  - 「ウィジェットを追加」押下時、ホーム画面に空きがなければその旨をダイアログで表示
- アプリ・フォルダ・QUICK ACCESS のボタンは、長押し→ドラッグで移動・削除（「2-1. ドラッグ＆ドロップ」参照）
- ウィジェット編集モード: ウィジェットのヘッダーや空きスロットなどの長押しで入り、移動・リサイズ・削除
  （アプリ・フォルダ・QUICK ACCESS のボタンの長押しは、ウィジェット編集モードよりドラッグを優先）
- ウィジェット編集モードは、アプリ起動などでランチャーから離れて戻ってきたときに自動解除
- ホームボタンを押すと、開いているポップアップ・ボトムシート・ダイアログ・フォルダ・ウィジェット編集モード・
  ドラッグをすべて閉じてホーム画面に戻る（`MainActivity` は `singleTask` で、`onNewIntent` で受け取る）
- 各種設定（テーマ・アクセントカラー・壁紙透過・スロット構成など）を `SharedPreferences` に永続化

## 2. ウィジェットキャンバス (`WidgetCanvas.kt` / `WidgetLayoutUtils.kt`)

- ホーム画面中央を細かいグリッドに区切り、ウィジェットを自由に配置
- ウィジェット編集モードでドラッグによる移動、四隅のハンドルによるリサイズ
- 移動ドラッグ中にドック付近へ「ここにドラッグして削除」ゾーンを表示し、ドロップで削除（確認ダイアログあり）
- 空き領域に「+ ADD WIDGET」タイルを表示（カスタマイズ画面で非表示にできる）
- 配置できるウィジェット
  - APP LIST（ACCESS GRID）/ CALENDAR / SYSTEM MONITOR / QUICK ACCESS: 各1個まで
  - APP SLOT（アイコンのみ / アプリ名つき）: アプリ1個分のショートカット。複数配置可（`StandaloneAppSlotSection.kt`）
  - 外部ウィジェット（他アプリのAppWidget）: 複数配置可（`AppWidgetHostSection.kt` / `AppWidgetPickerDialog.kt`）
- 外部ウィジェットはプレビュー画像つきの一覧から選択し、推奨サイズに応じたセル数で配置。
  バインド許可・設定画面が必要なウィジェットにも対応
- 外部ウィジェットが最小サイズでも画面に入り切らない場合は、追加できない旨をダイアログで表示
- 初回（未保存時）は画面モードごとのデフォルト配置を使用

## 2-1. ドラッグ＆ドロップ (`ui/drag/AppDragAndDrop.kt` / `ui/drag/AppDragOverlay.kt`)

- APP LIST・DOCK・アプリドロワー・フォルダの中のアプリ（APP LIST はフォルダも）を、長押し→ドラッグで持ち上げて移動
  - フォルダの中のアプリは、フォルダ内で並べ替え（入れ替え）できるほか、ポップアップの外へ持ち出すと
    ポップアップが透明になり、APP LIST・DOCK へ置ける（置いたらフォルダを閉じる）
  - フォルダの中から取り出して中身が1つになったフォルダは、残ったアプリのアイコン表示に戻る
  - アプリドロワーから持ち上げると、ドロワーを透明にしてホーム画面へそのまま配置できる（ドロップ後に閉じる）
- ドロップ先ごとの動作
  - 空きスロット: そこへ移動（アプリドロワーからの場合は追加）
  - APP LIST のアプリの上: 2つのアプリをまとめた新しいフォルダを作成
  - APP LIST のフォルダの上: フォルダの空きに追加（いっぱいの場合は追加しない）
  - DOCK の使用中スロットの上: ドラッグ元と入れ替え（DOCK はフォルダ非対応）
- ドラッグ中は画面上部に「削除」（スロットから外す。フォルダは削除）と「アンインストール」のエリアを表示
  （アプリドロワーからの場合は「削除」、フォルダの場合は「アンインストール」を表示しない）
- APP LIST・DOCK の左右の端に持っていくと、隣のページへ自動でスクロール
- QUICK ACCESS のボタンも長押し→ドラッグで、QUICK ACCESS 内での並べ替え（入れ替え）と「削除」ができる
  （アンインストールのエリアは表示しない）
- ドロップできない場所（QUICK ACCESS のボタンを APP LIST に、など）は強調表示せず、落としても何もしない

## 3. ヘッダー (`HeaderSectionLandscape.kt` / `HeaderSectionPortrait.kt`)

- 現在時刻・日付の表示（システムの毎分の時刻通知で更新。ホーム画面表示中のみ受信）
- バッテリー残量の円形インジケーター表示（残量変化の通知で更新。ホーム画面表示中のみ受信）
- 横画面・縦画面（大）: 中央に "MAIN TERMINAL" 風のステータス表示
- 再生中のメディアがあれば、バッテリー表示の左側に NowPlaying ウィジェットを表示（`NowPlayingWidget.kt`）
  - タイトル・アーティスト、再生位置のゲージ、前へ/再生・一時停止/次へ/停止して非表示のボタン
  - カード部分のタップで再生中のアプリを開く
- バッテリーコア中央の歯車タップでカスタマイズ画面（ボトムシート）を表示

## 4. カスタマイズ画面 (`CustomizeSheet.kt`)

- 壁紙の変更（端末の壁紙選択画面を開く）
- 壁紙透過モードのオン/オフ
- テーマ（ダーク/ライト）切り替え
- アクセントカラー1・2の変更（`AccentColorPickerDialog.kt` のカラーパレットを表示）
  - カラーサークル・明度スライダー・最近使った色・デフォルトに戻す
  - ウィジェットごとに、アクセントカラー1と2のどちらを使うかを選択（外部ウィジェットは対象外）
- アプリアイコンをオリジナルカラーに戻す（デュオトーン加工のオン/オフ）
- APP LIST の詳細設定（APP LIST の歯車ボタンと同じ設定画面を開く）
- QUICK ACCESS の詳細設定（QUICK ACCESS の歯車ボタンと同じ設定画面を開く）
- 「+ ADD WIDGET」タイルの表示/非表示
- グリッド線（ウィジェットの枠線）の一括表示/非表示と、ウィジェットごとの個別設定
- 端末設定・電源メニューへのボタン
- 項目が画面に収まらない小さい画面では、中身をスクロールして表示

## 5. アプリリスト / ACCESS GRID (`AccessGridSection.kt`)

- アプリアイコン・フォルダをグリッドで表示
- ヘッダーの歯車ボタンで APP LIST の設定（`SlotGridSettingsSheet.kt`）を表示
  - ICON ONLY: アイコンのみ（正方形スロット）の表示に切り替え（縦画面・横画面で別々に記憶）
  - 縦画面・横画面で同じ並びにする（デフォルトはオン）: オフにすると横画面用の並びを別に持つ
    （今の並びをコピーして始め、フォルダは複製する。オンに戻すと今表示している向きの並びにそろえる）
  - アイコンの並び: AUTO（デフォルト）または列数×行数（1〜8）を指定（画面モードごとに保存）
    - AUTO は、基準の列数×行数（縦画面（小）3×3、縦画面（大）4×3、横画面 3×5）を軸に、ウィジェットの実サイズに応じて自動調整
  - ページ数: 1〜10 で指定（画面モードごとに保存）。アプリ・フォルダが入っているページより少なくはできない
- 複数ページは `HorizontalPager` で横スワイプ。スロットが埋まっても自動ではページを増やさない
- 空きスロットのタップで、そのままアプリ選択を表示してアプリを追加
- アプリ・フォルダは長押し→ドラッグで移動・フォルダ化・削除（×ボタンの編集モードはない）
- 通知/バッジがあるアプリのアイコン右上にマークを表示

## 6. フォルダ (`FolderCard.kt` / `FolderContentsDialog.kt` / `FolderUtils.kt`)

- APP LIST でアプリの上に別のアプリを重ねるとフォルダを作成
- タップで、フォルダアイコンから拡大するアニメーションとともに中身をポップアップ表示
- フォルダ名の変更（名前のタップ）、空きスロットのタップでアプリの追加、アプリの起動
- 中のアプリは長押し→ドラッグで並べ替え・持ち出し・削除・アンインストール

## 7. ボトムドック (`BottomDockSection.kt`)

- よく使うアプリを最大8個まで配置できる固定ドック
- 縦画面は4個ずつのページを横スワイプで切り替え、横画面は8個を1行に並べる
- グリッドと同様、空きスロットへの追加・ドラッグでの移動・削除・通知バッジ表示に対応

## 8. アプリカード共通コンポーネント (`AppCard.kt` / `DockAppCard.kt` / `AppIconBitmap.kt`)

- アプリの実アイコンを、ロゴの形を保ったままアクセントカラーのデュオトーンに加工して表示
  （モノクロ用レイヤーを持つアイコンはそれを優先して使用）
- 「アプリアイコンをオリジナルに戻す」がオンの場合は、加工せず本来の色で表示
- 加工済みアイコンは共有キャッシュに保持し、複数箇所での表示やスクロール時の再加工を省く
- 通知/バッジありの場合、右上にドット状のマークを表示
- APP SLOT ウィジェットでは、ウィジェット編集モード時に右上へ削除ボタンを表示
- 壁紙透過モード時はパネルの不透明度を下げて背景を透過
- APP SLOT の削除ボタンでは「スロットから削除」か「アンインストール」かを選択（`AppActionDialog.kt`）

## 9. カレンダー (`CalendarSection.kt`)

- MONTHLY / WEEKLY / DAILY の3つの表示を、ヘッダーのボタンで順に切り替え
- `HorizontalPager` による左右スワイプ、またはヘッダーの `‹` `›` タップで前後の月・週・日へ移動
- 「TODAY」ボタンで今日を含むページへ戻る
- 端末カレンダー（`READ_CALENDAR` 権限）から予定を取得
  - MONTHLY: 予定がある日にドットマークを表示。日付タップで標準カレンダーアプリの該当日を開く
  - WEEKLY / DAILY: 予定の一覧を表示。予定のタップで標準カレンダーアプリの該当予定を開く
- 「今日」の日付をアクセントカラーでハイライト

## 10. SYSTEM MONITOR (`DeviceStatusSection.kt`)

- ストレージ使用量ゲージ（使用量/総容量、ホーム画面表示中のみ5秒間隔で更新）
- メモリ（RAM）使用量ゲージ（同上）
- **OPTIMIZE SYSTEM ボタン**
  - 演出のみ（実際のメモリ解放は行わない）。タップするとアイコン回転＋光の帯が流れるスキャンアニメーションを表示
  - 演出後にゲージを最新の値に更新し、「SYSTEM OPTIMAL」を数秒間表示

## 11. QUICK ACCESS (`QuickAccessSection.kt` / `SystemControlDialog.kt`)

- アプリのグリッドと同様に、ボタンを空きスロットへ追加。長押し→ドラッグで並べ替え・削除
  - 空きスロットでは、別のスロットに設定済みのボタンも選べる（確認のうえ、元のスロットから移動する）
- ヘッダーの歯車ボタンで QUICK ACCESS の設定（`SlotGridSettingsSheet.kt`）を表示
  - 縦画面・横画面で同じ並びにする（デフォルトはオン）: オフにすると横画面用の並びを別に持つ
  - ボタンの並び: AUTO（デフォルト）または列数×行数（1〜8）を指定（画面モードごとに保存）
  - ページ数: 1〜10 で指定（画面モードごとに保存）。ボタンが入っているページより少なくはできない
  - ボタンの表示: ICON ONLY / ICON+NAME / NAME ONLY（デフォルト）から選択。ICON+NAME でボタンが狭い場合は、
    アイコンの下に名前を小さく表示
- 配置できるボタン（それぞれアイコンつき）: SETTING（端末設定）/ WI-FI / DISPLAY / BLUETOOTH / DEVELOP（開発者向けオプション）/ APP（アプリ設定）/ WALL（壁紙設定）/ COLOR（カラーパレット）/ THEME（ダーク/ライト切替）/ VOLUME / BRIGHT /
  CLEAR（壁紙透過の切替）/ GRID（グリッド線の設定画面 `GridLinesSheet.kt` を開き、一括・ウィジェットごとに枠線の表示を切替）
- VOLUME: ボタンの上に縦スライダーを表示してメディア音量を調整。スピーカーアイコンでミュート切替（通知アクセスが必要な端末では案内を表示）
- BRIGHT: ボタンの上に縦スライダーを表示して画面の明るさを調整（システム設定の書き込み権限がなければ案内を表示）
- AUTO ではウィジェットのサイズに応じて列数・行数を自動調整。1ページに入り切らないボタンは横スワイプの
  後ろのページへ送られる（ウィジェットを縮めてもボタンは消えない）。左右の端へドラッグすると隣のページへ自動スクロール
- 壁紙透過モード時、ボタンの見た目を半透明化

## 12. アプリドロワー (`AllAppsDrawer.kt`)

- インストール済み全アプリの検索・一覧表示（ボトムシート）
- 「よく使うアプリ」欄（`PACKAGE_USAGE_STATS` 権限利用、過去1週間の使用時間上位8件。バックグラウンドで集計）
- 使用状況アクセス権限が無い場合は、設定画面へ誘導するボタンを表示
- 画面の向きに応じてグリッド列数を自動調整（縦3列/横5列）
- アプリの長押し→ドラッグでホーム画面へ配置、または画面上部のエリアでアンインストール

## 13. アプリ選択ダイアログ (`AppSelectorDialog.kt`)

- グリッド/ドック/APP SLOT/フォルダの空きスロットへ割り当てるアプリを検索・選択するボトムシート

## 14. 初回起動・権限 (`OnboardingScreen.kt` / `MissingPermissionsSheet.kt` / `OnboardingSteps.kt`)

- 初回起動時のオンボーディングで、次の設定へ順に案内
  - デフォルトのホームアプリに設定
  - 通知へのアクセスを許可
  - バッテリー最適化の対象から除外
  - 使用状況へのアクセスを許可（任意）
- オンボーディング完了後も、未設定の項目があればアプリの起動につき1回だけボトムシートで知らせる

## 15. 通知/メディア連携 (`CyberNotificationListener.kt`)

- `NotificationListenerService` により端末の通知状態を監視し、アプリごとの通知件数を保持
  - フォアグラウンドサービス通知（音楽再生・歩数計等）とグループのまとめ通知は除外
  - 常駐通知として実装されることが多い「アプリバッジ（未読件数）」も検知対象に含む
  - 通知の中身は保持せず、パッケージ名と件数のみを状態として保持
- 再生中（または一時停止中）のメディアセッションを監視し、NowPlaying ウィジェットに情報を提供・再生操作を中継
- セッション変更イベントを取りこぼす端末向けの保険として、ホーム画面表示中のみ定期的にセッション一覧を再取得
  （再生中は3秒、それ以外は20秒間隔）

## 16. 電源メニュー (`PowerMenuAccessibilityService.kt`)

- カスタマイズ画面の「電源メニュー」ボタンから、端末標準の電源メニュー（電源を切る/再起動）を開く
- アクセシビリティサービスの有効化が必要。未有効の場合は理由を説明し設定画面へ案内

## 17. アンインストール (`UninstallResultReceiver.kt`)

- `PackageInstaller` 経由でアンインストールを要求し、システムの確認画面を表示
- 実際にアンインストールが完了した場合のみ、グリッド/ドックのスロットから該当アプリを取り除く
- アプリのインストール・更新・削除を検知し、アプリ一覧をその場で更新

## 18. テーマ / 配色 (`CyberTheme.kt`, `Theme.kt`)

- ダーク/ライト2種類のサイバーパンク配色（背景・パネル・アクセント・文字・枠線・コアカラー）
- アクセントカラーは1・2の2種類をユーザーが変更可能。アクセントカラー上の文字色は明るさに応じて白/黒を自動選択
- `CompositionLocalProvider` によりアプリ全体へ配色を配布（ウィジェットごとにアクセントカラーを差し替え）

## 19. ユーティリティ (`AppUtils.kt` / `SystemStateEffects.kt` など)

- インストール済みアプリ一覧の取得（ラベルの昇順ソート）とアイコンの加工
- 使用状況統計からの「よく使うアプリ」算出
- 使用状況アクセス権限の付与状態チェック（通知アクセスは `CyberNotificationListener.kt` の `isNotificationListenerEnabled`）
- 時刻・バッテリー残量をシステムのブロードキャストで取得（ホーム画面表示中のみ受信）

## 未実装 / プレースホルダーのまま残っている項目

- ヘッダーの "TOKYO // MAIN TERMINAL" は固定の装飾テキストであり、現在地などとは連携していない
