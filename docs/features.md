# GridLauncher 機能一覧

対応する主要ソースファイルを併記する。

## 1. ホーム画面 (`CyberLauncherScreen.kt`)

- 画面の向き（縦/横）に応じてレイアウトを自動切替
- 縦画面時、画面幅 600dp を境に「デバイスステータス」と「カレンダー」の表示を出し分け
- 上方向へのスワイプでアプリドロワーを表示
- 画面の空白タップで編集モードを解除
- ダーク/ライトテーマの状態を `SharedPreferences` に永続化
- 壁紙透過モードの状態を `SharedPreferences` に永続化

## 2. ヘッダー (`HeaderSectionLandscape.kt` / `HeaderSectionPortrait.kt`)

- 現在時刻・日付のリアルタイム表示（1秒間隔更新）
- バッテリー残量の円形インジケーター表示
- 横画面: "MAIN TERMINAL" 風のステータス表示
- 縦画面: 気温表示欄（現状は "22° // TOKYO" のハードコード値、実データ未連携）
- バッテリーコア中央の歯車タップでカスタマイズ画面（ボトムシート）を表示

## 2-1. カスタマイズ画面 (`CustomizeSheet.kt`)

- 壁紙の変更（端末の壁紙選択画面を開く）
- 壁紙透過モードのオン/オフ
- テーマ（ダーク/ライト）切り替え
- アクセントカラーの変更（`AccentColorPickerDialog.kt` のカラーパレットを表示）
- アプリアイコンをオリジナルカラーに戻す（デュオトーン加工のオン/オフ）
- グリッド線（ウィジェットの枠線）の一括表示/非表示と、ウィジェットごとの個別設定
- 端末設定・電源メニューへのボタン

## 3. アクセスグリッド (`AccessGridSection.kt`)

- アプリアイコンを行×列のグリッドで表示（縦画面3×3、横画面3×5）
- 登録アプリ数がページサイズを超える場合、`HorizontalPager` で横スワイプ・複数ページ対応
- 空きスロットタップでアプリ選択ダイアログを開き、アプリを割り当て
- 長押しで編集モードに入り、右上の×アイコンでアプリの削除が可能
- 通知/バッジがあるアプリのアイコン右上にマークを表示

## 4. ボトムドック (`BottomDockSection.kt`)

- よく使うアプリを最大8個まで配置できる固定ドック
- 縦画面は `LazyRow`、横画面は均等幅の `Row` でレイアウト
- グリッドと同様、空きスロット追加・編集モードでの削除・通知バッジ表示に対応

## 5. アプリカード共通コンポーネント (`AppCard.kt` / `DockAppCard.kt`)

- パッケージ名に応じたカスタムアイコンマッピング（YouTube, Chrome, Gmail, Instagram 等、約25種類）
- カスタムアイコンが無い場合はアプリカテゴリ（ゲーム/動画/SNS等）に応じたフォールバックアイコンを表示
- それも無い場合はアプリ名の頭文字を表示
- 通知/バッジありの場合、右上にドット状のマークを表示
- 編集モード時、右上に削除ボタンを表示
- 壁紙透過モード時はパネルの不透明度を下げて背景を透過

## 6. カレンダーセクション (`CalendarSection.kt`)

- 月間カレンダーをパネル表示
- `HorizontalPager` により左右スワイプで前後の月へ実質無制限に移動可能（ヘッダーの `‹` `›` タップでも移動可）
- 端末カレンダー（`READ_CALENDAR` 権限）から当月の予定がある日を取得し、日付にドットマークを表示
- 日付タップで標準カレンダーアプリの該当日を開く
- 「今日」の日付をアクセントカラーでハイライト（実際の今日を含む月のページでのみ）

## 7. デバイスステータスセクション (`DeviceStatusSection.kt`)

- ストレージ使用量ゲージ（使用量/総容量、5秒間隔で更新）
- メモリ（RAM）使用量ゲージ（同上）
- **OPTIMIZE SYSTEM ボタン**
  - タップで自アプリの `System.gc()` を実行し、疑似的な「最適化」を行う
  - 実行中はアイコン回転＋光の帯が流れるスキャンアニメーションを表示
  - 実行前後の実際の空きメモリ量を比較し、「◯◯MB FREED」または「SYSTEM OPTIMAL」を結果として数秒間表示

## 8. クイックアクセスセクション (`QuickAccessSection.kt`)

- 設定 / Wi-Fi / 画面設定 / Bluetooth / 開発者向けオプション への直接遷移ボタン
- 壁紙透過モードのオン/オフ切替ボタン
- テーマ（ダーク/ライト）切替ボタン
- 壁紙透過モード時、ボタンの見た目を半透明化

## 9. アプリドロワー (`AllAppsDrawer.kt`)

- インストール済み全アプリの検索・一覧表示（ボトムシート）
- 「よく使うアプリ」欄（`PACKAGE_USAGE_STATS` 権限利用、過去1週間の使用時間上位8件）
- 使用状況アクセス権限が無い場合は、設定画面へ誘導するボタンを表示
- 画面の向きに応じてグリッド列数を自動調整（縦3列/横5列）

## 10. アプリ選択ダイアログ (`AppSelectorDialog.kt`)

- グリッド/ドックの空きスロットへ割り当てるアプリを検索・選択するボトムシート

## 11. 通知/バッジ連携 (`CyberNotificationListener.kt`)

- `NotificationListenerService` により端末の通知状態を監視
- フォアグラウンドサービス通知（音楽再生・歩数計等）は除外
- 常駐通知として実装されることが多い「アプリバッジ（未読件数）」も検知対象に含む
- 通知の中身は保持せず、パッケージ名の集合のみを状態として保持

## 12. テーマ / 配色 (`CyberTheme.kt`, `Theme.kt`)

- ダーク/ライト2種類のサイバーパンク配色（背景・パネル・アクセント・文字・枠線・コアカラー）
- `CompositionLocalProvider` によりアプリ全体へ配色を配布

## 13. ユーティリティ (`AppUtils.kt`)

- インストール済みアプリ一覧の取得（ラベルの昇順ソート）
- 使用状況統計からの「よく使うアプリ」算出
- 使用状況アクセス権限・通知アクセス権限の付与状態チェック

---

## 未実装 / プレースホルダーのまま残っている項目

- ヘッダーの気温表示（"22° // TOKYO"）は固定値であり、天気APIとの連携は未実装
- 天気・気象情報を取得するための外部通信手段（`INTERNET`権限含む）自体が現状存在しない
