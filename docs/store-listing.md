# Google Play 掲載文・PRO の価格（案）

## PRO の価格

- 買い切り（アプリ内アイテム `gridlauncher_pro`）。サブスクリプションにはしない
- 公開時は **¥480**（ドル圏は $3.99 前後）にし、レビューや売れ行きを見ながら **¥700 前後** まで上げる
  - Play Console でいつでも変えられ、購入済みの人には影響しない
  - 国ごとの価格は、基準の価格からの自動換算を少し整える程度でよい

## 簡単な説明（80文字以内）

サイバーパンクなダッシュボード型ホーム。時計・電池・予定・通知をひと目で。

## 詳しい説明の PRO 部分

```
■ GRIDLAUNCHER PRO（買い切り）
基本機能は無料で使えます。一度の購入で、次の拡張機能がすべて解放されます。

・テーマのプリセット、フォントの変更、アイコンパック対応
・ウィジェットのスタック（重ねてスワイプ切り替え・自動切り替え）
・NOW PLAYING ウィジェット、外部ウィジェットの無制限配置
・ジェスチャーへの動作の割り当て
・配色の細かいカスタマイズ、ヘッダーの文字の変更
・設定のバックアップ・復元

サブスクリプションではありません。広告なし、インターネット通信も行いません。
```

アプリ内の購入画面（`ProUpgradeDialog`）の文言は `ui/components/ProComponents.kt` の `ProFeatureGroups` にあり、
PRO の機能を増やしたときは、購入画面とこの掲載文の両方を直すこと。
